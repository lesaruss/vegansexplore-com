Connect a station (one time, about 2 minutes)
  1. On the station's computer, open claude.ai/code/routines and start a new routine. Name it Dispatcher Worker.
  2. For its instructions, tap and paste. Turn on the Supabase connector. Do not add a schedule.
  3. Save it, open it again, choose Edit, then add a trigger of type API and Generate token. Copy the link and the token it shows (the token is shown only once).
  4. Paste both below for that station and tap Connect.
